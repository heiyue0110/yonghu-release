# 永狐 2.0.0-alpha.4 私测通道

发布日期：2026-08-21

本通道用于永狐 2.0 Alpha 私测，与 1.4.16 稳定版完全隔离，不会改变稳定版的更新指向。

本次补齐：

- Windows Alpha 更新清单与安装器签名。
- 配装数据独立更新通道；打开配装页时检查兼容数据，无需重新安装应用。
- 手机端雷电模拟器白屏修复、原生横竖屏确认与远控输入回归。
- 账号、同步、主题、预警、星图、配装和手机页面的本地回归。

注意：

- Alpha 安装包仅供测试，未经商业代码签名，Windows 可能显示“未知发布者”。
- 下载、安装和重启仍需用户主动确认，软件不会静默安装。
- 登录、验证码和账号授权必须由用户本人完成。
- 手机系统级个推需要生产 AppID；缺少凭据时不会初始化。
