# 永狐 2.0.0-beta.2.1 修复公告

发布时间：2026-10-07

这是 Windows x64 Beta 测试修复版。beta.1 与 beta.2 用户均可直接升级。

## 修复内容

- 完整已知空间星图：修复已下载的数据缓存通过 blob URL 读取，被桌面安全策略拦截后只显示少量航线节点的问题。继续使用已校验缓存及安装包内置数据，不放宽安全策略。
- 星图数据更新后立即刷新；加载失败显示原因并提供重新加载按钮。虫洞地图规则保持原样。
- 设置的数据页新增软件“检查更新”入口，展示当前版本和检查结果；开启测试版通道立即检查。切换通道会作废旧结果，下载安装仍需主动确认。
- 聊天预警减少对最近历史和 JSON 镜像的重复读取，改善突发消息处理速度；持久化历史不设 500 条上限，已有去重与重放机制保持。
- 修正少量说明文字的字号和按钮名称，区分软件更新与数据更新。

## 检查范围

检查了主页面、预警处理与持久化、星图与路线、配装树和计算、虫洞查询、账号同步、远控、配置和更新链路。真实浏览器覆盖了缓存星图、数据更新失败保旧、软件更新入口及主页面切换。另有后端、前端/共享逻辑和 Windows 原生回归检查。

测试用例或模拟接口通过不代表所有真实环境均已验证：本次没有操作玩家的游戏客户端、真实 ESI 账号登录或手机实机。问题反馈可以继续提交。

## 升级方式

打开设置，开启“测试版通道”，点击“检查更新”，确认下载并安装。beta.1 不需要先安装 beta.2，可直接升级到 beta.2.1。保留现有配置；请与正式版分目录安装，不要同时运行。

本次仅发布 Windows x64；手机 APK 未重新发布。正式版仍为 1.4.16。
