# 永狐 2.0.0-beta.2 测试版更新公告

发布日期：2026-10-06

**这是 Beta 测试版，不是正式版。** 部分功能可能还不完整、暂时用不了，行为也可能在后续版本里改；请不要把它当成日常唯一在用的版本，也不要拿它替掉正式版。

使用前请看这三条：

- **不要和正式版装到同一个文件夹。** Beta 有自己的安装目录（默认 `%LOCALAPPDATA%\永狐 2.0 开发版`）和自己的数据目录；正式版仍在原目录，两者互不覆盖。
- **不要同时开着正式版和 Beta 一起用。** 两个版本都会读 ChatLogs、都会做预警监控，同时运行会出现重复提醒、重复通知和互相抢后端。
- **不要用 Beta 覆盖正式版。** 想回正式版，直接用 1.4.16 的安装包即可；Beta 不会改正式版的更新指向。

本轮测试重点：

- 预警提醒：同一事件含首次最多三次；解除后再次出现独立计数。系统通知未送达时提供页面提醒，保留默认提示音。
- 跃迁疲劳：完整显示等待时间与剩余分钟，可分别手动修正冷却与疲劳。
- 观察对象：支持一键清除，并在重新打开后保留结果。
- 局域网远控：优化截图采集与缩放，改善刷新体验；效果随设备、网络及分辨率变化。

2.0 的主要变化（相对 1.4.16 正式版）：

- 预警：距离过滤改为「被击方联盟 + 生产范围 + 统计时间」三项同时满足才提醒；范围外的击毁只留在列表里，不再弹窗也不再响铃；每条预警标出与生产位置的相对距离；舰船识别不再出现裸数字 ID；屏幕预警重做判定并新增「检测当前画面」。
- 生产位置风险：附近按 KM 扫描风险并给出综合评估，每条星系还带最近一次击杀——损失的是什么船（哪个联盟）、被什么船（哪个联盟）击杀、几人参与。
- 证据简报：从预警直达证据简报，结论前置，无效证据可展开看卡在哪一关，现场事实改为标签点选，四个出口写明去哪里、带什么。
- 快捷指令：Ctrl+K 新增查价、击毁查询与帮助指令，支持斜杠、中文、英文三种写法；面板按分组显示并带数量，选中即跳转并高亮。
- 星图与跳桥：旗舰跳规划改为选择船型与技能档位；新增跳跃疲劳计时器与「刷新主权」；跳桥路线会报出本趟含几段跳桥，并写明电容制排队、同联盟与亚旗舰限制。
- 配装：按角色技能计算，支持弹药兼容提示与装备限制校验，未登录时按全技能预览；配装数据可在后台热更新。
- 情报画像：支持角色与星系画像、军团联盟沿革、近期样本与反制建议，并可存成情报案例。
- 手机联动与远控：同一账号下自动登记设备并同步；局域网内可看电脑屏幕、切换副屏并远控指针与键盘。
- 迷你工具窗：置顶小窗可通过全局热键随时呼出，显示历史预警流，可直接静音或删除条目。
- 界面与体验：首页信息更集中；左侧导航按使用频率整理（设置移到最后、快捷指令排在诊断上面）；强调色跟随导航与控件，新增色相滑条与面板透明度。
- 数据与更新：设置里新增测试版通道开关与本次更新要点展示；星系表与类型名在后台按有效期拉取并逐文件校验，失败时保留原有数据。
- 账号：支持手机号与邮箱注册查重、双端资料一致、重启保留登录，并提供结构化的冲突选择。

注意：

- Beta 安装包仅供测试，未经商业代码签名，Windows 可能显示“未知发布者”。
- 下载、安装和重启仍需你主动确认，软件不会静默安装。
- 登录、验证码和账号授权必须由你本人完成。
- 本次发布 Windows x64 安装包；手机端安装包沿用已发布 Alpha，未作为本次 Beta 发布。手机联动、云端同步与屏幕识别仍需结合真实设备和游戏画面测试。
- 手机系统级个推需要生产 AppID；缺少凭据时不会初始化。
- 屏幕预警已修复通知重复与部分漏送路径；本地进红的真实画面识别效果尚待游戏内核实，不保证消除所有漏报。
