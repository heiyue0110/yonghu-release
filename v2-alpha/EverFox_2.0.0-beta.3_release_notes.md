# 永狐 2.0.0-beta.3 更新公告

2026-10-14 · Windows x64 / Android ARM64 公开测试版

本次在 beta.2.1 基础上完善桌面小窗、市场与配装工作台、手机设置和恢复链路。正式版仍为 1.4.16；Beta.3 不进入正式版更新通道。

## 本次变化

### 便捷小窗

预警、市场、路线、画像和虫洞入口嵌入原页面操作区；可重复打开独立小窗、复制当前工具、自由调整大小并切换置顶，任务栏可找回。

### 搜索与键位

市场、路线、画像与虫洞复用既有联想数据；设置可保存小窗和快捷指令键位，支持冲突反馈、恢复默认和重启恢复，初始引导提供小窗试用入口。

### 市场与角色

查价入口更名市场，收纳订单、钱包和采矿，保留角色页原入口；联系人与游戏通知等首次显示自动读取，角色变化作废旧响应并隐藏旧私有资料。

### 配装与航点

配装收藏、模板、作业参数与EFT导入直接呈现；配装保存和游戏航点写入核对当前角色、账号及权限，切换身份关闭旧确认，失败或不确定结果保留原因且不自动重试。

### 通知历史

手动导入游戏通知摘要，按账号、角色与通知编号去重；显示通知时间与记录时间，提供独立筛选；不自动提醒、不作为战斗证据，角色切换立即隐藏旧私有摘要。

### 手机设置

外观、预警、同步、版本与帮助通过独立设置首页进入，退出对应设置返回分类首页；保留原持久化控制器和既有主题，不把主题作为产品结构。

### 远控恢复

修正画面颜色转换与指针定位，输入按顺序发送；关闭、后台、会话失效和网络失败丢弃未发送旧操作并安全释放，恢复重新校准指针；已发送请求仍按等待和超时路径收尾。

### 账号与更新

旧启动会话刷新与旧配对读取不覆盖或清理新账号；普通访问失败保留可能有效的刷新凭据。数据页改善开关与布局，简易和详细说明保持同一批条目，只改变文案详略。

## 下载与更新

Windows 测试版用户可在「数据与更新」开启测试版通道后检查更新，下载与安装须主动确认。手机 Beta/RC 客户端读取测试版清单；Android 测试 APK 的下载、校验和系统安装确认分开显示。旧 Alpha 清单保留，不强制迁移。

Windows 保持 2.0 独立标识与安装目录，安装器拒绝覆盖 1.x 正式版目录。Android 沿用 com.everfox.companion 和现有 Debug 测试签名；versionCode 递增为 2000010。请保留已有应用数据，勿先卸载。真实手机覆盖升级及最新远控画面验收仍待完成。

## 验证与已知限制

桌面数据页、小窗入口与主题、通知筛选和角色失效清理已用真实 Vue 页面及浏览器夹具验证；手机下载页断网重试、账号恢复及远控生命周期已用实际组件和模拟传输验证。双端类型检查和生产构建通过。这些证据不代表真实 EVE 写入、真机远控或手机升级验收。

游戏通知为 ESI 已记录历史摘要，按来源与发生时间展示，不冒充实时战斗证据，不自动触发新提醒。配装及航点写入仍须明确确认并等待真实服务回执；本轮没有执行真实游戏操作。

Windows 有 Tauri 更新器签名，未做商业 Authenticode 代码签名，系统可能提示未知发布者。Android 为 Debug 测试签名；未配置推送凭据时，不承诺系统推送可用。新版本不会自动安装。
