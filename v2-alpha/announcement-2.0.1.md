# 永狐 2.0.1 更新公告

发布日期：2026-10-23  
升级范围：从 2.0.0 到 2.0.1；从 1.4.16 仍需首次手动安装。  
本次仅提供 Windows x64；Android 继续使用 2.0.0 的 ARM64 包，未随本次更新。

## 设置与界面

设置页按用途重新排列。「数据」页顺序调整为软件更新、程序补丁、测试版通道、本次更新要点、本地数据；右列为离线外壳、保存设置、配置与缓存目录、配置备份、清除缓存，危险操作置于最末。原来重复出现的「本地数据」标题被合并，保存设置补充了一行用途说明。

分类页签（核心、外观、监控、提醒、数据、窗口、测试）在页面滚动时固定在顶部，长页面切换分区不必回到最上方。

「本次更新要点」不再内嵌整段列表，改为一个入口按钮。打开后是居中弹窗，条目按两列卡片排列，底部提供关闭；窄窗口自动改为单列。

更新入口去重：「数据 → 软件更新」负责检查、下载与安装；「窗口 → 关于」只保留更新源配置（主清单、可信镜像、单源超时），不再重复放置检查按钮。

## 配装

弹药页改为平铺列表。进入后按当前武器过滤，只列出可装填的弹药，单击一行即装填到同型号的整组炮台；原本需要逐槽展开的流程被移除。装填结果会同时反映在武器 DPS、应用 DPS 与高槽弹药图标上，装填操作不写入配装历史。

## EVE 总览覆盖工具

工具的说明改为完整流程：选择一个源总览，勾选要覆盖的账号（可多选），再执行准备配置。文案纠正为「会先备份所选目录，再把你选定的源总览覆盖到勾选的账号上；没勾的账号不动」，不再声明「不覆盖任何配置文件」。

账号勾选框恢复为普通勾选框，不再套用全站开关样式；此前它会把账号名压住。目标列表补充「全选」「清空」两个入口。工具仍然只做扫描、备份、停止进程和打开目录，不自动修改未勾选的账号。

## 更新与安装

电脑正式更新源切换到 2.0.1。更新清单的下载地址在本版期间先使用 GitHub Release 直链；官网下载按钮使用镜像地址，便于国内网络直接下载。安装包签名与旧版本连续，安装前会校验签名。

便捷小窗的全局快捷键在启动时注册。主键 Ctrl+Shift+K 被其它软件占用时，按顺序尝试 Ctrl+Shift+Alt+K、Ctrl+Alt+K、Alt+Shift+K，设置页会显示实际生效的组合键。

## 从 2.0.0 或 1.4.16 升级

2.0.0 用户可以直接在应用内检查更新，也可以下载安装包覆盖安装；数据目录、账号、配装、预警历史与缓存位置都不变。覆盖安装只替换所选安装目录中的程序，不清理其它版本。

1.4.16 用户的旧客户端只认原先的更新清单地址，本次需要手动下载安装包覆盖安装一次。旧版配置与 ESI 凭据会在首次启动时写入 .upgrade-backup-1x 备份，旧授权可能因权限结构变化需要重新授权。

已知问题：本版发布后的短时间内，部分 2.0.0 客户端的应用内更新只显示「打开下载」，不显示「确定更新」，此时用下载到的安装包直接覆盖安装即可。相关更新器行为已列入 2.0.2 修正。

## 校验

安装包 EverFox_2.0.1_x64_setup.exe，大小 73,585,185 字节，SHA256 3846ACE83A299A20A1B756D87C00314C63C3E26B44F3F4384C5B6C881AB21A1C。更新清单内的 minisign 签名使用与安装包更新相同的公钥，安装前由客户端校验。

## 后续版本

2.0.2 集中处理更新链路：各更新源的失败原因可见、签名编码兼容、安装包下载失败自动换镜像、安装前校验 SHA256，并把版本号、打包、签名、清单生成与上传写成可重复执行的脚本。产业与合同、手机系统推送、真机覆盖升级与远控仍按原计划推进。
